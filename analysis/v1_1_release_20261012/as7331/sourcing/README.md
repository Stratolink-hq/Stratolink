These are observed stocks/prices, not reserved parts or delivery promises.

The independent reviewer checked [Vishay doc 28952](https://www.vishay.com/docs/28952/mcr0201at-mca1206at.pdf), Rev. 28-May-2026: the order code explicitly decodes D=25 ppm/K, B=0.1%, 3304=3.3 MΩ, and the MCU0805 precision range extends to 7.5 MΩ. A 0603 substitution is not justified by this table (2 MΩ limit). The primary dimensions-and-mass table lists **4.6 mg** for the MCU0805 body (solder excluded), so this reference adds about 0.0046 g before its solder and routing. No inspected primary AS7331 package mass is available; do not present a total new-circuit mass as measured. This meets AS7331's 3.3 MΩ ±1%, at most 50 ppm/K requirement. An ordinary 100 ppm/K thick-film substitution does not. Captures and primary review are retained alongside this file and under `../review/`.

C14 and new C23 use the existing **Samsung CL05B104KO5NNNC C1525**, 100 nF, X7R, 16 V, 0402. Supply qualification and local bypass geometry are part of the circuit review.
