        - generic: I'm using this sensor with an STM32F103C8T6 (blue pill) microcontroller. It works great. This sensor will be incorporated into a wearable UV dosimeter. I found that you don't need to run the long setup code you download from Github. If you want to change the gain and integration time you change the default value in register 6. Then all you need to do write "power_on_and_measure" (0x83) to register 0, wait about 65 ms, and then read 6 bytes starting at register 2. The 6 bytes cover the values for UV A, B, and C. There is some information in the datasheet that seems to indicate that you can convert the raw count data into uWatts/cm^2, but I couldn't figure out how to do that. An example of how to do this in the datasheet or in a forum would be helpful. I have a calibrated UV diode that allows me to make that conversion for UV B, which is what I'm most interested in. Overall, this sensor is easy to use and provides useful data once calibrated.
